The official e-commerce website for **Aura Athletics**, the performance activewear brand built specifically for the **Aura AI Nutrition & Fitness Ecosystem**.

---

## 🌟 Key Features

1. **Full Bilingual Support (EN & AR)**:
   - Dynamic English and Arabic RTL layout with Cairo & Plus Jakarta Sans typography.
   - 1-click instant language toggle.

2. **Multi-Currency Engine**:
   - Native toggle between USD (`$`), Egyptian Pounds (`EGP ج.م`), and Euro (`€`).
   - Dynamic threshold calculation for free worldwide shipping ($75 / 1500 EGP).

3. **High-Performance Activewear Catalog**:
   - Men's 2-in-1 compression shorts, dry-vent stringers.
   - Women's 100% squat-proof seamless leggings, contour sports bras.
   - Heavyweight 460 GSM organic cotton pump covers and oversized hoodies.
   - Titan-Grip silicone lifting straps & insulated ThermoMatte steel gym shakers.
   - Dynamic color swatch selector, size picker (XS to XXL), and real-time hover zoom.

4. **Connected Activewear (Aura App Sync)**:
   - Built-in NFC smart apparel showcase connecting physical gear to the Aura mobile fitness application.
   - Unlocks exclusive workout splits and 3 months of Aura Premium AI meal scanning.

5. **Laboratory-Grade Fabric Tech Showcase**:
   - `AuraStretch 360™` 4-way elastic memory.
   - `DryBreeze™` laser-cut spinal aeration.
   - `SilverGuard™` silver ion anti-microbial odor protection.
   - `SculptSeam™` zero-chafe bonded seams.

6. **Interactive Smart Size Advisor**:
   - Bio-mechanical size calculator based on height, weight, and preferred fit (Compression, Athletic, Relaxed/Oversized).

7. **Interactive Bag & Checkout**:
   - Slide-over drawer cart with free-shipping progress meter.
   - Promo coupon engine (supports `AURA10` for 10% off and `FITNESS20` for 20% off).
   - Mock checkout supporting Credit/Debit Card, Apple Pay/Google Pay, and Cash on Delivery (Egypt & GCC) with celebratory confetti.

## 🚀 Quick Start

```bash
# Navigate to web directory
cd web

# Install dependencies (if not already installed)
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
